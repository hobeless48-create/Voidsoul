=== EVENT SYSTEM DATA (events_db.ts) ===

[STORY TEMPLATE STRUCTURE]
interface StoryTemplate {
  title: string;          // Display title with emoji
  desc: string;           // Description text
  stars?: number;         // Difficulty/rarity (1-3)
  choices: {              // Array of 2-3 choices
    label: string;         // Button text
    effectText: string;    // Tooltip/description
    effect?: ChoiceEffect; // Effect logic (see below)
  }[];
}

[EVENT ROLL SYSTEM]
- Player sees 3 choices (from map roll: 1-2 combat, 3 elite, 4/6 event, 5 shop)
- Events are pulled randomly from MYSTERY_STORIES array
- IMPORTANT: Duplicate events should not appear in same 3-choice roll
- Pre-boss area always: "Rest Before Boss" + Boss Door + Final Preparations

[EFFECT TYPE REFERENCE]
ChoiceEffect types used:
  type: "item" | "gold" | "hp" | "hp_pct" | "xp" | "stat_check" | "random" | "talent_point" | "status" | "combat" | "none"
  
  stat_check: { stat: "STR"|"DEX"|"CON"|"INT"|"FTH"|"CHA"|"LCK", threshold: number, successEffect, failEffect }
  
  Effects can chain via successEffect/failEffect for multi-reward outcomes
